- (constraint) ADOPTED từ PRD+UX: Next.js App Router + Tailwind CSS + Clerk Auth + shadcn/ui. Routes đã xác định: /, /sign-in, /sign-up, /home, /search, /movie/[id], /watch/[id], /my-list, /history, /admin, /admin/movies/*. Auth gate: mọi content route yêu cầu đăng nhập. Admin panel desktop-only.
- (decision) Database: Supabase (PostgreSQL). Binds schema design theo relational model (User, Movie, Genre, Watchlist, WatchHistory tables). Prevents: dùng document-style embedding thay vì foreign keys. Quan trọng: Clerk + Supabase cần cấu hình JWT integration — Supabase RLS nhận Clerk JWT thay vì Supabase Auth JWT.
- (decision) Data access: API Routes (/api/...) làm lớp trung gian duy nhất. Server Components không query DB trực tiếp — đọc qua fetch nội bộ hoặc shared service layer. Prevents: một số chỗ dùng Server Actions, chỗ khác dùng API Routes — mâu thuẫn pattern. Enables React Native client dùng cùng API sau này.
- (decision) Admin role: Clerk publicMetadata.role = 'admin'. Middleware đọc role từ JWT — không query DB. Route /admin/* bảo vệ hoàn toàn ở tầng middleware. Prevents: một số chỗ check role qua DB, chỗ khác qua token — mâu thuẫn. RLS policy trên Supabase cũng dùng claim từ JWT.
- (decision) Rendering strategy: Movie pages (home, /movie/[id]) dùng ISR — revalidate ~60s hoặc cache tag bị bust khi admin write. User-specific pages (/my-list, /history, /watch) force-dynamic, no-store. Search luôn dynamic. Prevents: dùng dynamic cho mọi trang (bỏ lợi thế caching) hoặc ISR cho trang cá nhân (data stale).
- (decision) Client state: không dùng TanStack Query hay SWR. useState + fetch thuần cho watchlist toggle và search. Optimistic update thủ công (đổi UI trước, rollback nếu API lỗi). Prevents: mix TanStack ở một số chỗ và fetch thủ công ở chỗ khác — mâu thuẫn pattern.
- (decision) Video player: YouTube IFrame API (JS SDK). Poll currentTime mỗi 30s, gọi POST /api/history/[id]/progress để lưu timestamp. Prevents: dùng raw iframe không có API (không đọc được currentTime). Không dùng react-player — giữ đơn giản, tự implement với YouTube IFrame API.
- (decision) Deployment: Vercel (free tier). Production + preview deployments. Env vars: NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY, CLERK_SECRET_KEY, NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_ANON_KEY, SUPABASE_SERVICE_ROLE_KEY. Không self-host.
- (version) Next.js 16.4.0 (Turbopack default, React 19.3, stable Oct 2026). @clerk/nextjs 7.9.x (Core 3). @supabase/supabase-js latest. TypeScript 5.x. Tailwind CSS 4.x. shadcn/ui latest. Vercel platform.
